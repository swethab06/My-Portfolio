Project

I developed an Employee Management System using React.js for the frontend, Spring Boot for the backend, and MySQL for database management. The application has an authentication page through which the user can log in before accessing the employee management features. After login, the user can view employee details in a table. The table displays Employee ID, Employee Name, Employee Date of Joining, and Salary. It also contains Edit and Delete buttons for each employee. In the backend, I followed a layered architecture using Controller, Service, Repository, and Employee Model/Entity classes. The Employee Controller handles REST API requests, the Service layer contains the business logic, and the Repository layer communicates with the MySQL database using Spring Data JPA. I created an employees table in MySQL, where employee_id is the primary key. The application supports CRUD operations such as adding, viewing, updating, and deleting employee records. I used Postman to test the REST APIs and verify that the backend operations were working correctly. React communicates with the Spring Boot REST APIs to retrieve and update the employee data displayed in the frontend table.

During the project, I learned many concepts such as React navigation, responsive design, semantic HTML tags, CSS Grid, and Bootstrap cards. This project improved both my frontend development skills and my problem-solving abilities.
